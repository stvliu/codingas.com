## 模型能力矩阵

模型按能力标签分类，控制台与 Plan Catalog API 支持按能力筛选：

| 能力标签 | 说明 |
|---------|------|
| `streaming` | 支持流式响应 |
| `functionCalling` | 支持 Function Calling / Tools |
| `vision` | 支持多模态视觉输入 |

> **多模态限制**：OpenAI 兼容端点的 `messages[].content` 当前为 String 类型，`image_url` 数组形式的多模态输入暂不支持；Anthropic 端点的 `content` 为 Object 数组，支持多模态。详见 [对话补全 API](/api/chat-completions/)。

## 模型发现 API

调用 `GET /v1/models` 获取当前 API Key 可见的模型列表（OpenAI 兼容格式）：

```bash
curl https://{gateway-host}/v1/models \
  -H "Authorization: Bearer sk-xxx"
```

```json
{
  "object": "list",
  "data": [
    { "id": "gpt-4o", "object": "model", "created": 1700000000, "ownedBy": "openai" }
  ]
}
```

> 可见性基于 API Key 关联的 `applicationId`，仅返回该应用授权渠道下的可见模型。端点细节见 [模型列表 API](/api/models/)。

## 定价查询

通过 Plan Catalog API 查询套餐与定价（管理 API，需登录态）：

| 端点 | 说明 |
|------|------|
| `GET /api/v1/plan-catalogs/providers` | 供应商目录 |
| `GET /api/v1/plan-catalogs` | 套餐目录 |
| `GET /api/v1/plan-catalogs/{planCode}` | 套餐详情 |
| `GET /api/v1/plan-catalogs/{planCode}/pricing` | 套餐定价 |
| `GET /api/v1/plan-catalogs/models` | 模型列表（支持 `keyword` / `capability` 过滤） |

控制台 **Catalog** 模块提供可视化浏览。管理 API 总览见 [管理 API 索引](/api/admin-index/)。
