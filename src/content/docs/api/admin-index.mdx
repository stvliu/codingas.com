# 管理 API 索引

管理 API 供控制台与运维调用，需 **Sa-Token 登录态**（`Authorization: Bearer <sa-token>`）。调用方模型调用 API（`/v1/*`、`/anthropic/v1/*`）使用 [调用方 API Key](/admin/apikeys/)，与管理 API 认证体系不同。

写操作冲突（如复制时名称重复）返回 `409 CONFLICT`，资源不存在返回 `404 NOT_FOUND`，统一 `ApiResponse` 格式。

## 认证与当前用户

| 端点 | 说明 |
|------|------|
| `POST /api/v1/auth/login` | 登录（返回会话 token） |
| `POST /api/v1/auth/logout` | 登出 |
| `GET /api/v1/auth/me` | 当前用户信息 |
| `PATCH /api/v1/auth/me/password` | 修改当前用户密码 |
| `GET /api/v1/me/api-keys` | 查询我的 API Key |

## 用户与密钥

| 端点 | 说明 |
|------|------|
| `/api/v1/users` | 用户 CRUD、`PATCH /{id}/state` 启停、`PUT /{id}/roles` 角色、`POST /{id}/reset-password` 重置密码、`GET /users/{userId}/api-keys` 用户的 Key |
| `/api/v1/user-api-keys` | 调用方 API Key CRUD（`GET /{id}/detail` 详情），创建时绑定用户与应用 |

## 应用与渠道

| 端点 | 说明 |
|------|------|
| `/api/v1/applications` | 应用 CRUD、渠道授权（含 priority） |
| `/api/v1/channels` | 渠道 CRUD（列表支持 `providerId` / `billingMode` / `sortBy` / `sortOrder`）、`POST /{id}/copy` 复制、状态切换、端点管理、健康检查、应急熔断 |
| `/api/v1/channels/{channelId}/credentials` | 渠道凭证（上游 API Key）管理 |
| `/api/v1/channels/{channelId}/models` | 渠道模型映射（含上游模型名更新、状态管理） |
| `/api/v1/provision` | 渠道配置供给（按套餐 / 供应商 / 模型批量开通） |
| `/api/v1/providers` | Provider CRUD、连通性测试 |
| `/api/v1/protocols` | 已注册协议元数据 |

## 模型与目录

| 端点 | 说明 |
|------|------|
| `/api/v1/models` | 模型管理 CRUD、`POST /{id}/copy` 复制、`POST /{id}/unlock` 解锁、`PATCH /{id}/state` 状态（区别于调用端点 `/v1/models`） |
| `/api/v1/plan-catalogs` | 套餐目录与定价查询 |
| `/api/v1/catalog/sync` | 模型目录同步（`POST` 手动触发、`GET /status` 状态） |

## 计量、容灾与统计

| 端点 | 说明 |
|------|------|
| `/api/v1/token-limits` | Token 限额管理（含 `PATCH /{id}/reset-usage` 重置用量） |
| `/api/v1/stats` | 用量统计（概览、`/trend?days=` 按天趋势、`/model-usage?limit=` 模型用量 TopN） |
| `/api/v1/resilience/events` | 容灾事件查询（转移事件流、`/exhausted` 候选耗尽告警） |

## 审计与设置

| 端点 | 说明 |
|------|------|
| `/api/v1/audit-logs` | 管理端操作审计日志（分页查询、`DELETE` 按时间清理） |
| `/api/v1/settings` | 系统设置键值（`GET` 全部、`PUT /{key}` 更新） |

## 体验

| 端点 | 说明 |
|------|------|
| `POST /api/v1/experience/chat` | Playground 流式体验（SSE，指定渠道直连调试） |
| `GET /api/v1/experience/providers/{providerId}/models` | 体验端点的供应商模型列表 |
