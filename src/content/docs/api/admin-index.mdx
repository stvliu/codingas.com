# 管理 API 索引

管理 API 供控制台与运维调用，需 **Sa-Token 登录态**（`Authorization: Bearer <sa-token>`）。调用方模型调用 API（`/v1/*`、`/anthropic/v1/*`）使用 [调用方 API Key](/admin/apikeys/)，与管理 API 认证体系不同。

## 认证与当前用户

| 端点 | 说明 |
|------|------|
| `/api/v1/auth` | 登录 / 登出 |
| `/api/v1/me` | 当前用户信息、修改密码 |

## 用户与密钥

| 端点 | 说明 |
|------|------|
| `/api/v1/users` | 用户 CRUD、角色管理（ADMIN / USER） |
| `/api/v1/user-api-keys` | 调用方 API Key CRUD、额度 / 模型白名单 / IP 限制 / 过期 |

## 应用与渠道

| 端点 | 说明 |
|------|------|
| `/api/v1/applications` | 应用 CRUD、渠道授权（含 priority） |
| `/api/v1/channels` | 渠道 CRUD、状态切换、端点管理、健康检查、应急熔断 |
| `/api/v1/channels/{channelId}/credentials` | 渠道凭证（Provider API Key）管理 |
| `/api/v1/channels/{channelId}/models` | 渠道模型映射 |
| `/api/v1/provision` | 渠道配置供给 |
| `/api/v1/providers` | Provider CRUD、连通性测试 |
| `/api/v1/protocols` | 协议元数据 |

## 模型与定价

| 端点 | 说明 |
|------|------|
| `/api/v1/models` | 模型管理 CRUD（区别于调用端点 `/v1/models`） |
| `/api/v1/plan-catalogs` | 套餐目录与定价查询 |

## 计量与容灾

| 端点 | 说明 |
|------|------|
| `/api/v1/token-limits` | Token 限额管理 |
| `/api/v1/stats` | 用量统计查询 |
| `/api/v1/resilience/events` | 容灾事件查询 |

## 体验

| 端点 | 说明 |
|------|------|
| `/api/v1/experience` | Playground 体验接口 |
