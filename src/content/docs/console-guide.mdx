# 控制台快速上手

codingas.com 控制台是网关的可视化管理后台，基于 React + Ant Design 构建。本文导览 9 大功能模块，帮助管理员与开发者快速定位操作入口。

## 登录

访问网关地址（如 `http://localhost:8080`）进入登录页。默认 `local` profile 预置示例账号：

| 角色 | 用户名 | 密码 | 权限 |
|------|--------|------|------|
| 管理员 | `admin` | `admin` | 全部功能 |
| 普通用户 | （示例数据） | （示例数据） | 受限视图 |

> 生产环境请务必修改默认密码。认证体系详见 [用户与认证](/admin/users/)。

## 模块导览

### 1. 仪表盘（Dashboard）

- **AdminView**：管理员视图，展示全局用量、渠道健康、熔断状态概览
- **UserView**：普通用户视图，展示个人 API Key、用量统计

### 2. 快速开始（Quickstart）

面向开发者的自助入口，四步完成首次调用：

1. **模型卡片浏览**：按关键词搜索、按能力标签（vision / functionCalling / streaming）筛选模型
2. **API Key 选择 / 创建**：选择已有 Key 或新建
3. **代码片段生成**：自动生成 cURL / Python / Node / Java 示例，支持 OpenAI / Anthropic 双协议
4. **Playground 试玩**：在线调试，支持流式，显示 Token 用量与耗时

详见 [Playground 体验](/developer/playground/)。

### 3. 应用管理（Applications）

应用是权限与行为的聚合根，承载 API Key 归属与渠道可见性。

- 创建 / 编辑应用（code / name / description）
- 管理应用下的 API Key
- 配置应用授权的渠道及**应用级转移优先级**

详见 [应用管理](/admin/applications/)。

### 4. 渠道管理（Channels）

渠道是上游接入的核心，功能最丰富的模块：

- **创建向导**：引导式新建渠道
- **详情抽屉**：查看 / 编辑渠道全貌
- **分组列表 / 表格视图**：按 Provider 分组或平铺
- **熔断器**：一键强制熔断 / 恢复端点
- **连通性测试**：验证渠道可用性
- **凭证管理**：Provider API Key 的增删与轮换
- **端点管理**：配置协议端点
- **模型映射**：上游模型名与网关模型名的映射
- **配额设置**：渠道级配额
- **批量导入 / 导出**：批量管理渠道

详见 [渠道管理](/admin/channels/)。

### 5. 模型管理（Models）

维护网关对外暴露的模型清单：创建模型、编辑模型属性、关联渠道。

详见 [模型与定价](/developer/models-pricing/)。

### 6. 用户管理（Users）

管理员管理用户账号与角色（ADMIN / USER），并为用户分配 API Key。

详见 [用户与认证](/admin/users/)。

### 7. 下游密钥（ApiKeys）

调用方 API Key 的集中管理：创建 / 查询 / 删除 / 配置额度、模型白名单、IP 限制、过期时间。

详见 [调用方密钥管理](/admin/apikeys/)。

### 8. 套餐目录（Catalog）

浏览供应商、套餐与模型定价目录，对应 `PlanCatalogController` 查询能力。

### 9. 容灾大盘（Resilience）

端点级熔断器状态大盘（CLOSED / OPEN / HALF_OPEN），查看容灾事件与故障转移记录。

详见 [容灾与高可用](/admin/resilience/)。

## 典型操作路径

| 目标 | 路径 |
|------|------|
| 首次调用模型 | Quickstart → 选模型 → 建 Key → 复制代码 |
| 接入新上游 | Channels → 创建向导 → 配置凭证 / 端点 / 模型映射 → 连通性测试 |
| 给应用授权渠道 | Applications → 选应用 → 渠道管理 → 勾选渠道并设优先级 |
| 排查调用失败 | Resilience → 看熔断状态 → 查容灾事件 → 结合 traceId 查日志 |
| 限制某 Key 用量 | ApiKeys → 选 Key → 配额 / 模型白名单 / IP 限制 |

> 控制台所有写操作均通过 [管理 API](/api/admin-index/) 实现，本文档不逐项截图，请以实际界面为准。
